# Источники данных

[English](../en/sources.md) | [Հայերեն](../hy/sources.md) | **Русский**

Раздел «External trade database» сайта Статистического комитета Республики Армения (Армстат):
<https://armstat.am/en/?nid=160>. Раздел существует на трёх языках; язык задаётся сегментом пути URL:

| язык | ISO 639-1 (в БД) | сегмент URL | пример |
|---|---|---|---|
| английский | `en` | `en` | <https://armstat.am/en/?nid=160> |
| армянский | `hy` | `am` | <https://armstat.am/am/?nid=160> |
| русский | `ru` | `ru` | <https://armstat.am/ru/?nid=160> |

## Структура раздела

| nid | что это | тип | годы |
|---|---|---|---|
| 160 | индексная страница раздела | ссылки на подстраницы | — |
| 148 | база данных по товарам (ТН ВЭД, 4 знака) | интерфейс запросов | годовые 1995–2026, месячные 2007–2026 |
| 159 | база данных по странам («до 2016 г.») | интерфейс запросов | годовые 1995–2025, месячные 2003–2025 |
| 717 | база данных по странам («2017–2025») | интерфейс запросов | годовые и месячные 2017–2026 |
| 766 | «Внешняя торговля РА по ТН ВЭД ЕАЭС, 2 знака» | файлы xlsx (+7z) | бюллетени 2018–2024 |
| 777 | «Внешняя торговля РА по ТН ВЭД ЕАЭС, 4 знака» | файлы xlsx | 2018–2025 |
| 778 | «Внешняя торговля РА по ТН ВЭД ЕАЭС, 10 знаков» | файлы xlsx (+7z с ТН ВЭД 2017) | 2018–2025 |

Годы приведены на момент сбора (ноябрь 2026); актуальный список вычисляется заново при каждом запуске
`armstat-trade catalog` (см. `data/catalog/pages.json`, `data/catalog/files.json`, `data/catalog/db_options/`).
2026 год — неполный (данные по сентябрь включительно).

## Файлы (nid 766 / 777 / 778)

* Ссылки имеют вид `https://armstat.am/file/doc/<file_id>.<ext>`.
* **Один и тот же файл** публикуется на всех трёх языковых версиях страниц — различаются только
  тексты ссылок. Сами xlsx двуязычные (армянский + английский). Поэтому файлы скачиваются один раз,
  а тексты ссылок на трёх языках сохраняются в `meta_file.title_en/hy/ru`.
* На страницах есть **скрытые ссылки** (с пустым текстом) — это более ранние редакции файлов
  (2018 г. — предварительные данные, 2020 г. для 10-знакового уровня). Они загружаются в БД с
  `meta_file.hidden = TRUE`, `meta_workbook.is_current = FALSE`.
* Архив `99516683.7z` содержит ранний вариант 2-знакового бюллетеня за 2018 г. (`2_nish_2018.xlsx`) и PDF;
  архив `99528903.7z` — документ ТН ВЭД ЕАЭС 2017 на русском языке (`ТНВЭД_2017.doc`, 58 МБ),
  из которого извлекаются русские названия разделов и групп.

Подробное описание содержимого файлов — в [files.md](files.md); полный перечень — в
[inventory.md](inventory.md) (генерируется).

## Веб-база данных (nid 148 / 159 / 717)

Интерфейс — HTML-форма с методом GET:

| параметр | значение |
|---|---|
| `nid` | 148 (товары) / 159, 717 (страны) |
| `thid[]` | код товара (4 знака без ведущего нуля, напр. `101`) или страны (ISO 3166-1 numeric); `0` — все |
| `years[]` | годы для **годовых** значений (можно несколько) |
| `year[]` + `monid[]` | годы и месяцы (1–12) для **месячных** значений |
| `submit=Search` | — |

Пример: `https://armstat.am/en/?nid=717&thid[]=643&years[]=2024&submit=Search`.

Особенности, выявленные при разработке:

1. **Постраничный вывод.** Результат показывается по 25 строк (`&offset=N` — номер страницы).
   Месячный запрос «все товары» за год — около 12 тыс. строк (≈ 490 страниц).
2. **Выгрузка в Excel.** Ссылка «Download Excel file» (`/excelopen.php`) отдаёт **весь** результат
   последнего запроса одним HTML-документом в формате «Excel HTML» и с полной точностью
   (до 5 знаков после запятой; на HTML-странице значения округлены до 1–2 знаков). Без заголовка `Referer`
   сервер отвечает `403`. Сборщик использует именно выгрузку: новый сеанс → запрос → выгрузка.
3. **Выгрузка может вернуть чужой запрос.** Сервер хранит «последний запрос» не строго в рамках сеанса:
   при первом сборе 13 из 378 выгрузок (3,4 %) содержали результаты чужих запросов (другой таблицы,
   другого года) или были пустыми.
   Поэтому каждая выгрузка проверяется (`parsers/db_export.validate`): число колонок, год, коды периодов
   и число строк, объявленное пагинатором страницы запроса. Неверные выгрузки запрашиваются повторно.
4. **Код периода**: 1–12 — месяц, 13 — год (в HTML отображается как «Year»).
5. **Нули и прочерки.** В HTML нулевые значения показаны «-», в выгрузке — `0`. В БД хранится `0`.
   В базе по странам за 1995–2002 гг. импорт по стране происхождения нулевой — заполнен только импорт
   по стране отправления.
6. **Коды стран в выгрузке отсутствуют** — только названия. Строки упорядочены по коду страны, что
   позволяет различить одноимённые страны (в форме дважды встречается «Serbia» — коды 688 и 891,
   в армянской и русской версиях дважды «Самоа» — 16 и 882). В выгрузках ранних лет встречаются
   устаревшие названия («United States», «FYR of Macedonia», «Korea, DPR of», «Individual» = физические
   лица, код 997 и др.), для них ведётся словарь `reference.COUNTRY_NAME_ALIASES`.
7. **Страницы 159 и 717 — один backend.** Обе страницы возвращают данные за любые годы, значения
   совпадают (проверка `qc_db_country_overlap`). В БД для лет < 2017 берутся данные nid 159,
   для 2017+ — nid 717, остальное хранится в `stg_db_country`.
8. **Названия на трёх языках.** Значения во всех языковых версиях идентичны (проверка
   `qc_db_language_consistency`), различаются названия стран/товаров и заголовки.
   Все три языковые версии выгрузок сохранены (`data/raw/db/nid<nid>/<lang>/`) и загружены
   в `stg_db_country` / `stg_db_commodity`.
9. **Исторические коды товаров.** В выгрузках ранних лет есть 4-значные коды, отсутствующие в
   текущей форме (например, 0509, 4108–4111, 8520); их названия берутся из самих выгрузок.

## Обозначения в опубликованных таблицах

| знак | смысл | в БД |
|---|---|---|
| `-` | явление отсутствует / нет данных | `NULL` (исходный текст — в `raw_xlsx_cell`) |
| `X` | не применимо / конфиденциально | `NULL` |
| `◊` после года (напр. `2021◊`) | в файлах не расшифрован; ставится у прошлых лет многолетних таблиц (вероятно, уточнённые данные) | год без значка |
| `*`, `**` | сноски (тексты сносок — в `raw_xlsx_cell`) | — |

Важные сноски листа «Countries» 2-знаковых бюллетеней:

* `*` — из-за особенностей взаимной торговли стран ЕАЭС и методологии ЕЭК вместо показателя
  «импорт по стране торговли» используется «импорт по стране отправления» (consignment).
* `**` — данные о Нагорном Карабахе (код 999, alpha-2 `ARTH`) в таможенных декларациях отсутствуют и
  отражают только энергетический сектор (источник — Минэнерго РА и крупные энергетические компании).
