# Հայաստանի արտաքին առևտուրը — Արմստատի տվյալները DuckDB-ում

[English](README.md) | **Հայերեն** | [Русский](README.ru.md)

Հայաստանի Հանրապետության արտաքին առևտրի տվյալների հավաքում, նորմալացում և փաստաթղթավորում։ Տվյալները
հրապարակված են Հայաստանի Հանրապետության վիճակագրական կոմիտեի (Արմստատ) կայքի «External trade database»
բաժնում՝ <https://armstat.am/en/?nid=160>։

Գործընթացը հավաքում է բաժնում հրապարակված **ամեն ինչ**՝ **բոլոր երեք լեզուներով** (անգլերեն, հայերեն,
ռուսերեն).

* **վեբ տվյալների բազան** (հարցումների միջերես)
  * ըստ գործընկեր երկրների՝ տարեկան տվյալներ 1995 թվականից, ամսական՝ 2003 թվականից (nid 159 և 717)
  * ըստ ԱՏԳ ԱԱ-ի (արտաքին տնտեսական գործունեության ապրանքային անվանացանկ, ռուս.՝ ТН ВЭД) 4-նիշ ապրանքային
    դիրքերի՝ տարեկան 1995 թվականից, ամսական՝ 2007 թվականից (nid 148)
* **xlsx ֆայլեր**՝ ըստ Եվրասիական տնտեսական միության արտաքին տնտեսական գործունեության ապրանքային անվանացանկի
  (ԵԱՏՄ ԱՏԳ ԱԱ) 2-, 4- և 10-նիշ մակարդակների, 2018–2025 թթ. (nid 766, 777, 778), ներառյալ թաքցված վաղ
  խմբագրությունները և 7z արխիվները (դրանց թվում՝ ԵԱՏՄ ԱՏԳ ԱԱ 2017 թ. փաստաթուղթը)

Արդյունքը DuckDB `data/armstat_trade.duckdb` տվյալների բազան է՝ եռալեզու տեղեկատուներով, նորմալացված փաստերի
աղյուսակներով, բոլոր սկզբնական բջիջների և վեբ բազայի ներբեռնումների անկորուստ պատճենով, տվյալների որակի
ստուգումներով և փաստաթղթերով։

## Պատրաստի տվյալներ — թողարկումներ

Տվյալների բազան և հում տվյալները git-ում չեն պահվում (բազան գերազանցում է GitHub-ի 100 ՄԲ ֆայլի
սահմանաչափը, իսկ պատմությունը կմեծանար յուրաքանչյուր վերակառուցման հետ)։ Յուրաքանչյուր հավաքում հրապարակվում
է որպես ռեպոզիտորիայի **թողարկում** ([Releases](https://github.com/opendataam/arm-ext-trade/releases))՝
`data-YYYY-MM-DD` պիտակով (հավաքման ամսաթիվը). պիտակը ցույց է տալիս կոդի այն commit-ը, որով կառուցվել է բազան։

| թողարկման ֆայլ | բովանդակություն | չափ* |
|---|---|---|
| `armstat_trade.duckdb.xz` | DuckDB տվյալների բազա | ~25 ՄԲ (չսեղմված՝ 124 ՄԲ) |
| `armstat_trade-parquet.zip` | բոլոր աղյուսակներն ու ներկայացումները Parquet ձևաչափով + տվյալների բառարան | ~40 ՄԲ |
| `armstat_trade-raw.tar.xz` | հում տվյալներ՝ կայքի էջեր, xlsx/7z, վեբ բազայի ներբեռնումներ (`raw/`) և մանիֆեստներ (`catalog/`) | ~46 ՄԲ |
| `SHA256SUMS` | ստուգիչ գումարներ | |

\* 2026-11-05 պատկերի (snapshot) համար։

```bash
make install
make download            # վերջին թողարկումը. բազա -> data/armstat_trade.duckdb (SHA256 ստուգմամբ)
make lab                 # օրինակներով նոթատետր
```

Այլ տարբերակներ՝ `make download-parquet` (Parquet → `data/parquet/`), `make download-raw` (հում տվյալներ →
`data/raw/`, որից հետո `make build`-ը վերակառուցում է բազան՝ առանց կայքին դիմելու), կոնկրետ պատկեր՝
`make download TAG=data-2026-11-05`։ Առանց Python-ի՝
`curl -LO https://github.com/opendataam/arm-ext-trade/releases/latest/download/armstat_trade.duckdb.xz && xz -d armstat_trade.duckdb.xz`։

Պատկերը ճշգրիտ վերակառուցելու համար անցեք դրա պիտակին (`git checkout data-2026-11-05`). `data/catalog/`-ի
մանիֆեստները պետք է համապատասխանեն պատկերի հում տվյալներին (կամ օգտագործեք
`python -m armstat_trade download --part raw --with-catalog`)։

Նոր պատկեր հրապարակելու համար (սպասարկողներին) հավաքեք տվյալները (`make all`), commit և push արեք
մանիֆեստների փոփոխությունները, ապա գործարկեք `make release`։ Արխիվները և `RELEASE_NOTES.md`-ն ստեղծվում են
`data/release/<tag>/`-ում և վերբեռնվում `gh release create`-ով (անհրաժեշտ են `gh` և գրելու իրավունք.
`make release-pack`-ը միայն փաթեթավորում է)։

## Արագ մեկնարկ — ամբողջը կառուցել ինքնուրույն

```bash
make install   # ստեղծում է .venv և տեղադրում փաթեթը dev + notebook լրացումներով (uv-ի միջոցով, եթե առկա է. Python ≥ 3.10)
make all       # catalog → fetch-files → fetch-db → tnved → build → docs  (~40–60 րոպե, հիմնականում ներբեռնում)
```

Երբ միջավայրը ստեղծված է, `make`-ի բոլոր թիրախներն ավտոմատ օգտագործում են `.venv/bin/python`-ը
(Homebrew/Debian Python-ում համակարգային `pip install`-ն արգելված է, PEP 668)։ Այլ ինտերպրետատոր՝
`make build PY=python3`։

Կամ քայլ առ քայլ (ակտիվացված միջավայրում՝ `source .venv/bin/activate`).

```bash
python -m armstat_trade catalog       # բաժնի էջերը en/hy/ru լեզուներով → data/catalog/*.json
python -m armstat_trade fetch-files   # xlsx/7z → data/raw/files (+ 7z-ի բացում)
python -m armstat_trade fetch-db      # վեբ բազա Excel ներբեռնման միջոցով → data/raw/db (≈ 380 հարցում)
python -m armstat_trade tnved         # բաժինների/խմբերի ռուսերեն անվանումները ԱՏԳ ԱԱ 2017-ից (անհրաժեշտ է textutil կամ soffice)
python -m armstat_trade build         # → data/armstat_trade.duckdb
python -m armstat_trade docs          # → docs/data_dictionary.md, docs/{en,hy,ru}/inventory.md
```

7z-ի բացման համար անհրաժեշտ է `7zz`/`7z` (օրինակ՝ `brew install sevenzip`) կամ `py7zr` փաթեթը
(`.venv/bin/python -m pip install '.[7z]'` կամ `uv pip install --python .venv/bin/python '.[7z]'`)։
`fetch-db`-ի կրկնակի գործարկումը ներբեռնում է միայն բացակայողը և միշտ թարմացնում է վերջին երկու տարիները
(`--refresh-last N`). այն նաև վերստուգում է սկավառակի վրա արդեն առկա ներբեռնումները և կրկին հարցում անում
անվավերների համար։

Հարցման օրինակ.

```bash
duckdb data/armstat_trade.duckdb -c "
  SELECT year, round(sum(export_kusd)/1e3) AS export_musd, round(sum(import_origin_kusd)/1e3) AS import_musd
  FROM v_db_country_annual GROUP BY year ORDER BY year"
```

## Jupyter նոթատետր օրինակներով

[`docs/examples.ipynb`](docs/examples.ipynb) նոթատետրը պարունակում է հարցումների, աղբյուրների համեմատության և
գծապատկերների օրինակներ (նոթատետրի տեքստը ռուսերեն է)։ Այն պահվում է կատարման արդյունքներով, ուստի կարելի է
կարդալ անմիջապես GitHub-ում։ Ինտերակտիվ աշխատելու համար.

1. Տեղադրեք միջավայրը (ստեղծում է `.venv`՝ JupyterLab-ով, matplotlib-ով և Python միջուկով).

   ```bash
   make install
   ```

2. Համոզվեք, որ բազան առկա է՝ `data/armstat_trade.duckdb` (ներբեռնեք `make download`-ով կամ կառուցեք՝
   առաջին անգամ `make all`, իսկ եթե հում տվյալներն արդեն սկավառակի վրա են՝ `make build`)։

3. Գործարկեք JupyterLab-ը նոթատետրով.

   ```bash
   make lab
   ```

   Բացվում է դիտարկիչ նոթատետրով (`http://localhost:8888/lab/tree/docs/examples.ipynb`), ֆայլերի պատուհանում
   երևում է ամբողջ ռեպոզիտորիան։ Սերվերի կարգավորումները գտնվում են
   [`scripts/jupyter_lab_config.py`](scripts/jupyter_lab_config.py)-ում՝ նախագծի սեփական JupyterLab
   աշխատանքային տարածք `.jupyter/`-ում (այլ նախագծերի ներդիրները չեն վերականգնվում) և միջուկի հետ կապ unix
   սոկետներով՝ TCP-ի փոխարեն։ Նույնը՝ առանց `make`-ի.

   ```bash
   source .venv/bin/activate
   jupyter trust docs/examples.ipynb
   jupyter lab --config scripts/jupyter_lab_config.py docs/examples.ipynb
   ```

   `jupyter trust`-ը նոթատետրը նշում է որպես վստահելի ձեր օգտատիրոջ համար. դրա արդյունքները ստացվել են ոչ ձեր
   դիտարկիչում, և առանց դրա JupyterLab-ը հայտնում է `Notebook ... is not trusted` և թաքցնում HTML/JS
   արդյունքները (PNG գծապատկերներն ու աղյուսակները ցուցադրվում են ամեն դեպքում)։

4. Ստուգեք միջուկը վերին աջ անկյունում. **Python 3 (ipykernel)**-ը `.venv`-ի միջուկն է
   (`.venv/bin/jupyter kernelspec list`-ը ցույց է տալիս `.venv`-ի ներսում գտնվող ուղի)։

5. Կատարեք բջիջները. **Run → Run All Cells** կամ հերթով՝ `Shift+Enter`։ Առաջին բջիջը գտնում է ռեպոզիտորիայի
   արմատը (`pyproject.toml`-ով) և բազան բացում միայն ընթերցման համար, ուստի Jupyter-ը կարելի է գործարկել
   ռեպոզիտորիայի ցանկացած թղթապանակից։

6. Կանգնեցնելու համար սեղմեք `Ctrl+C` այն տերմինալում, որտեղ աշխատում է `make lab`-ը, և հաստատեք `y`-ով։

**VS Code.** բացեք `docs/examples.ipynb`-ը, սեղմեք **Select Kernel → Python Environments** և ընտրեք
`.venv/bin/python`-ը (անհրաժեշտ է Jupyter ընդլայնումը)։

Օգտակար է իմանալ.

* Եթե մեկ այլ գործընթաց բազան բացել է **գրելու համար** (օրինակ՝ `duckdb data/armstat_trade.duckdb` առանց
  `-readonly`-ի), նոթատետրը չի կարող միանալ. փակեք այդ գործընթացը։
* Բազան վերակառուցելուց հետո (`make build`) վերագործարկեք միջուկը (**Kernel → Restart Kernel**). բաց կապը
  շարունակում է տեսնել հին ֆայլը։
* Commit անելուց առաջ թարմացրեք պահված արդյունքները բոլոր բջիջների մեկ մաքուր, հաջորդական կատարմամբ՝
  `make notebook` (առանց դիտարկիչի. կատարում է նոթատետրը և արդյունքները գրում ֆայլում)։

## Ռեպոզիտորիայի կառուցվածքը

```
├── README.md                  անգլերեն տարբերակ. README.hy.md — հայերեն (այս ֆայլը), README.ru.md — ռուսերեն
├── Makefile                   գործընթացի հրամանները
├── pyproject.toml             armstat_trade փաթեթ (CLI՝ armstat-trade)
├── src/armstat_trade/
│   ├── config.py              ուղիներ, բաժնի էջեր, լեզուներ, HTTP կարգավորումներ
│   ├── http.py                HTTP հաճախորդ. կրկնակի փորձեր, դադարներ հարցումների միջև, սեսիաներ
```

| `v_file_hs10_current` | 10-նիշ կոդեր. քանակ, տոննա, ԱՄՆ դոլար (2018–2025) |

## Ինչ հաշվի առնել

* Չափման միավորները սկզբնաղբյուրինն են և նշված են սյունակի անվան մեջ (`value_kusd`՝ հազ. ԱՄՆ դոլար,
  `value_usd`՝ ԱՄՆ դոլար, …)։
* Ամփոփ տողերը (`row_type = 'total'`, `'chapter'`, `'group'`, …) պահվում են մանրամասն տողերի հետ միասին.
  ֆիլտրեք դրանք։
* Ֆայլերը հրապարակումներ են՝ իրենց թողարկման ամսաթվի դրությամբ, իսկ վեբ բազան պարունակում է ավելի ուշ
  ճշգրտումներ։ Նույն տարվա արժեքները տարբեր աղբյուրներում կարող են տարբերվել (տե՛ս `qc_file_vs_db_hs4`)։
* 2026 թվականը թերի է։
